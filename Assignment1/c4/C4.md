# C4 — Reproducible Database Setup

## Purpose

C4 requires the database to be rebuilt from an empty database without manually typing SQL commands inside PostgreSQL.

The project uses two files:

- `schema.sql` — creates the complete database structure and constraints.
- `seed.sql` — inserts sample data.

## Setup

### 1. Remove the existing database

```bash
dropdb -U postgres assignment1
```

### 2. Create a fresh empty database

```bash
createdb -U postgres assignment1
```

### 3. Run the schema

```bash
psql -U postgres -d assignment1 -f schema.sql
```

### 4. Run the seed data

```bash
psql -U postgres -d assignment1 -f seed.sql
```

## Expected Result

Starting from a completely empty database:

1. The database is recreated.
2. `schema.sql` creates all tables and constraints.
3. `seed.sql` inserts valid sample data.
4. No manual SQL commands are required.
5. Both files execute without errors.

## Verification

Connect to the database:

```bash
psql -U postgres -d assignment1
```

Check the tables:

```sql
\dt
```

Check the seeded data:

```sql
SELECT * FROM users;
SELECT * FROM projects;
SELECT * FROM project_members;
SELECT * FROM tasks;
SELECT * FROM tags;
SELECT * FROM task_tags;
SELECT * FROM comments;
```

If the tables exist and the sample data is present, the C4 setup is working correctly.
